# Accessibility

## Commitment

The Marketplace Platform is designed to be usable by people with disabilities. **WCAG 2.1 AA** is the target for any web UI.

## Supported Environments

### Browsers

- Chrome (latest 2 versions)
- Firefox (latest 2 versions)
- Safari (latest 2 versions)
- Edge (latest 2 versions)

### Assistive Technology

- Screen readers: NVDA, JAWS, VoiceOver, TalkBack
- Keyboard-only navigation
- Zoom/screen magnification up to 200%

### OS/Device Ranges

- Windows 10/11
- macOS
- Linux
- iOS and Android (mobile browsers)

## Known Limitations

- No ARIA labels implemented yet on legacy components (Phase 7+)
- Color contrast compliance pending design system finalization (Phase 7)
- Keyboard traps may exist in embedded iframes (not yet implemented)

## How to Report Barriers

Use the [issue template](.github/ISSUE_TEMPLATE/bug.md) tagged with `accessibility`, or email rasimaghayev@gmail.com. Response timeline follows the [SECURITY.md](SECURITY.md) P2/P3 schedule.
